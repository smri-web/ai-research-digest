AgentSSL: Can MLE Agents Leverage Unlabeled Data?

Ethan Lin, Akanksha Sarkar, Ziang Liu et al. · arXiv

What they studied: Researchers studied if machine learning agents can use unlabeled data to improve performance.

Why they studied it: Current machine learning agents need a lot of labeled data, which is hard to get in new areas.

Method: They framed semi-supervised learning as a program search problem for agents.

Findings and results: Agents outperformed human-engineered methods in 8 of 12 settings, improving by up to 21.8%. Program selection was a major bottleneck, reducing performance by up to 47%.

Benefits and impact: This work shows agents can adapt existing techniques and perform well with limited labeled data.

Read the full breakdown

Machine learning agents typically need extensive labeled data, which is a challenge for new applications. This research explored if these agents could leverage unlabeled data, a common scenario in real-world problems. They designed a system called Agentic Semi-Supervised Learning (AgentSSL), where agents search for optimal programs to solve tasks. The agents combined and adapted existing semi-supervised learning techniques. They surpassed human-engineered baselines in 8 out of 12 tests, with performance gains up to 21.8%. However, selecting the best program was a significant hurdle, causing performance drops of up to 47%. To address this, they created ProgramSelectBench, a benchmark with 16,977 programs, to study program selection methods. They also tested AgentSSL on real-world ecology tasks.

Scalable Conversational Assessment: Chat-Based Exams with a Two-Agent LLM Pipeline

Geoffrey Challen, Craig Zilles · arXiv

What they studied: Researchers studied how to create scalable, interactive exams using AI.

Why they studied it: Oral exams are effective for assessing student reasoning but do not scale well.

Method: They developed a two-agent LLM system for text-based conversational assessments. One agent interviews the student, and a hidden evaluator guides the interview and tracks student progress.

Findings and results: The system was tested with simulated students and deployed in a small AI literacy course. Review of transcripts identified areas for improving follow-up questions and ensuring accurate grading.

Benefits and impact: This system offers a way to conduct interactive assessments at scale, addressing a limitation of traditional oral exams.

Read the full breakdown

Oral exams allow instructors to ask students for their reasoning and follow up on unclear answers. However, these exams are not practical for large numbers of students. This paper introduces a new system that uses two AI language models to conduct interactive, text-based exams. One AI acts as an interviewer, while a second, hidden AI evaluates student responses against a rubric and guides the interviewer. The system was tested with AI-simulated students and then used in a small AI literacy course. The researchers found areas to improve the AI's ability to ask follow-up questions and ensure that only student contributions were graded.

Introducing Our Smallest, Most Efficient Model: Muse Ember

Simon Willison · Simon Willison

What it covers: Meta AI released Muse Ember, a small and efficient model for complex reasoning and agent tasks.

Why it matters now: This model competes with existing offerings like Claude Haiku and GPT Luna, providing another option in the market.

Key takeaway: Muse Ember is designed for tasks such as tool calls, coding, routing, extraction, and long document parsing.

Benefits and impact: It offers competitive pricing, especially for shorter prompts, making advanced AI capabilities more accessible.

Read the full breakdown

Meta AI introduced Muse Ember, a new model for tasks like tool calls and long document parsing. It is designed to be small and efficient. For shorter prompts, it costs $0.10 per million input tokens and $0.50 per million output tokens. This pricing matches GPT-6 Luna and Claude Haiku 5.5. For prompts longer than 200,000 tokens, Muse Ember's input price increases to $0.20 per million tokens. Its cached input price is $0.004 per million tokens for prompts up to 200,000 tokens.

aws-emulator

Simon Willison · Simon Willison

What it covers: AWS released an official emulator for local testing of its services. It allows developers to run tests without needing a paid API key.

Why it matters now: This tool simplifies the development and testing workflow for AWS users. It removes a common barrier to local development.

Key takeaway: AWS now provides an official local emulator for its services.

Benefits and impact: Developers can test AWS service clones locally. This reduces costs and streamlines the testing process.

Read the full breakdown

AWS has launched an official emulator called aws-emulator. This tool lets developers test against local versions of AWS services. It eliminates the need for a paid API key during testing. The emulator is written in Rust and saw 29,684 commits in its first three weeks. It currently requires Docker to run on macOS or Windows. The hope is for a single binary in the future for easier integration into test suites.
