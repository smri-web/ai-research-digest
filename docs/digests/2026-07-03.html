DiScoFormer: One transformer for density and score, across distributions

Hugging Face · Hugging Face

What it covers: DiScoFormer is a new transformer model. It estimates both density and score functions.

Why it matters now: Current methods often require separate models or training for these functions. This model unifies them.

Key takeaway: One transformer can learn multiple related functions across different data distributions.

Benefits and impact: This simplifies the process of using score-based generative models. It could lead to more efficient AI model development.

Read the full breakdown

DiScoFormer is a single transformer architecture. It learns two important functions: density and score. The density function describes the probability distribution of data. The score function indicates the direction of steepest increase in probability. Traditionally, these functions are learned by separate models or through complex training procedures. DiScoFormer handles both simultaneously across various data distributions. This unification streamlines the development of generative AI models, particularly those that rely on score matching.

Using DSPy to evaluate and improve Datasette Agent's SQL system prompts

Simon Willison · Simon Willison

What it covers: This article describes using DSPy to evaluate and improve system prompts for Datasette Agent's SQL query feature. The goal was to enhance the agent's ability to answer user questions by executing read-only SQL.

Why it matters now: The research was prompted by a keynote on DSPy, indicating current interest in tools for optimizing LLM prompts.

Key takeaway: DSPy helped identify specific prompt improvements, such as including column names in schema listings to prevent errors and retry loops.

Benefits and impact: Improved system prompts lead to more accurate and efficient SQL query generation by the Datasette Agent, reducing errors and improving user experience.

Read the full breakdown

Simon Willison used DSPy to refine the system prompts for Datasette Agent's SQL capabilities. The agent's feature allows it to execute read-only SQL queries to answer user data questions. An asynchronous research task was set up using Claude Code for web with Claude Fable 5. Fable tested with GPT 4.1 mini and nano, identifying several areas for improvement. A key finding was that the original prompt's schema listing, which only included table names, led to column-name guessing and error-retry loops. The recommendation was to either include column names in the prompt's schema listing or modify the advice against calling 'describe_table'.

Fable's judgement

Simon Willison · Simon Willison

What it covers: This article discusses an effective prompting strategy for large language models like Fable and Opus.

Why it matters now: The strategy helps optimize token usage and model efficiency, especially with impending price increases for models like Fable.

Key takeaway: Granting AI models autonomy to make decisions, such as when to write tests or which sub-model to use, improves performance and resource management.

Benefits and impact: This approach can lead to more efficient use of AI resources and potentially better task execution by leveraging the model's inherent capabilities.

Read the full breakdown

The article highlights a prompting technique for Fable and Opus models. Instead of giving explicit instructions for every scenario, users should allow the models to use their own judgment. For example, rather than specifying when to run tests, users should let Fable decide. Another tip is to instruct Fable to delegate smaller coding tasks to less powerful models. This conserves valuable tokens, especially as model prices are set to increase. The author provides a prompt used with Claude Code to illustrate this delegation strategy.

AI & psychology / mental health

Where do LLMs Fall Short in CBT-Guided Affective Reasoning?

Vaishnavi Sinha, Pooja Guttal, Pranay Deep Reddy Katike et al. · arXiv

What they studied: Researchers studied how Large Language Models (LLMs) apply Cognitive Behavioral Therapy (CBT) principles in dialogue.

Why they studied it: LLMs can answer CBT exam questions but struggle to apply CBT effectively in conversations, often defaulting to validation and reflection.

Method: They developed a knowledge-guided framework for CBT dialogue, using Beck's Cognitive Conceptualization, SNOMED CT concepts, and a Multiple Chain-of-Thought (MCoT) strategy selection.

Findings and results: Introducing protocol definitions via single chain-of-thought prompting did not change LLM behavior. MCoT improved strategy selection, but the effect was small (1.2-1.3%), and models remained biased towards validation and reflection.

Benefits and impact: The work provides a metric, Protocol Leverage Force (F), to measure how much an intervention shifts an LLM's default response in CBT-guided affective reasoning.

Read the full breakdown

Large Language Models (LLMs) are good at answering theoretical questions about Cognitive Behavioral Therapy (CBT), scoring up to 96% on licensing exams. However, in actual conversations, they tend to over-rely on validation and reflection, even when other CBT techniques are needed. This research explored why LLMs struggle to apply CBT effectively. They introduced a framework that breaks down user narratives using CBT structures and guides the LLM to choose between different CBT strategies like Socratic Questioning or Alternative Perspectives. While this guidance improved strategy selection, the change in LLM behavior was small, only about 1.2-1.3%. LLMs still showed a strong bias towards validation and reflection, indicating that knowing CBT theory does not automatically lead to effective application in practice.

Copewell: A Multi-Agent Swarm Architecture for Equitable Mental Wellness Support

Seren Yenikent, Jack Vinijtrongjit, Katherine Ng · arXiv

What they studied: The paper studied how a multi-agent AI system could improve access to mental wellness support.

Why they studied it: Nearly one billion people globally suffer from mental health disorders, but 75% in low- and middle-income countries lack treatment. Current AI solutions have high abandonment rates and do not provide immediate, measurable relief.

Method: They developed Copewell, a multi-agent swarm system, using human-centered AI principles. It integrates multi-source data, maps emotions using Russell's Circumplex Model, and delivers dual-mode interventions.

Findings and results: Copewell's design includes a privacy-first architecture, an Ethics Supervisor agent, and participatory design with mental health practitioners. Early engagement and beta deployment are informing future evaluations.

Benefits and impact: This work aims to expand access to mental wellness support and demonstrates how AI architecture can incorporate equity and safety from the start.

What it adds to the future: The work identifies directions for future empirical evaluation and contributes to responsible AI discourse.

Read the full breakdown

Mental health disorders affect almost one billion people worldwide, with 75% in low- and middle-income countries not receiving treatment. Existing AI wellness tools often fail due to high abandonment rates and a lack of immediate, tailored support. Researchers developed Copewell, a multi-agent AI system, to address these issues. It uses a multi-source assessment framework, maps emotions to route users to specialized AI agents, and combines conversational support with sensory wellness protocols. The system was designed with privacy, ethical oversight, and input from mental health practitioners. Early testing is guiding future development and evaluation.

AI & human behavior

Behavior-Adaptive Conversational Agents: Toward a Fluid Personality Framework

Hasibur Rahman, Smit Desai · arXiv

What they studied: The paper studied how conversational agents' personalities and personas should change based on the situation.

Why they studied it: Current conversational agents often have fixed personalities, which can be ineffective in different contexts.

Method: The authors propose a Fluid Personality Framework to adapt agent behavior.

Findings and results: Evidence suggests moderate personality expression is best for trust and adoption. Context-appropriate metaphors improve user experience.

Benefits and impact: This framework aims to improve user experience and effectiveness of conversational agents in various applications.

Read the full breakdown

Large language model conversational agents are common. They can change their personality and role. Most agents currently use a fixed personality and style. This can lead to problems when the situation changes, like in medical advice or fitness coaching. The authors propose a Fluid Personality Framework. This framework adapts the agent's role, like coach or tutor. It also adjusts personality intensity (low, medium, or high). This adaptation depends on the task, user goals, and urgency.
