Quoting Geoffrey Huntley

Simon Willison · Simon Willison

What it covers: This article describes a method to enforce the use of a diagnostics library in AI agents.

Why it matters now: It addresses the challenge of maintaining consistent code practices when AI agents generate or modify code.

Key takeaway: A pre-commit Git hook can automatically detect and correct agents that bypass standard observability modules.

Benefits and impact: This approach ensures all code uses the intended diagnostics, improving system reliability and monitoring.

Read the full breakdown

Geoffrey Huntley proposes a system to ensure AI agents use a specific diagnostics library. He uses a pre-commit Git hook to check code changes. This hook scans the 'git diff' for direct calls to observability modules. If an agent bypasses the diagnostics module, the commit fails. The system then prompts the agent to use the correct library. This method reportedly achieves 100% compliance.

Tree Appreciator

Simon Willison · Simon Willison

What it covers: A developer used Claude Opus 5.5 Max to create a game called 'Tree Appreciator'. The game is a spot-the-difference type featuring two algorithmically generated trees.

Why it matters now: This project demonstrates the capability of large language models like Claude to generate complex, interactive applications from simple prompts.

Key takeaway: Prompting AI with 'make sure it is fun' can lead to surprisingly compelling and well-designed game mechanics.

Benefits and impact: AI can significantly reduce development time for creative projects, as Claude spent 3 hours and 7 minutes generating the game.

Read the full breakdown

A developer used the Claude iPhone app to prompt Claude Opus 5.5 Max. The prompt requested a Three.js game named 'Tree Appreciator' where players compare two AI-generated trees. Claude spent 3 hours and 7 minutes processing the request. The resulting game is a spot-the-difference experience with music, animation, and achievements. The developer noted that including 'make sure it is fun' in the prompt was effective.
