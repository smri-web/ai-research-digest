Read the full breakdown

Meta has introduced Muse Glimmer, a 30 billion parameter model. It is released under an Apache 2.0 license. The model is optimized for end-to-end agentic task completion, showing strong success rates on benchmarks like DeepSearch QA and SWE-Bench. It also demonstrates reliable tool use, handling various function calls with precise schemas. Additionally, Muse Glimmer is designed for multi-step reasoning, maintaining coherent plans across complex workflows. The model was tested using LM Studio and a coding agent plugin.

GitHub Models is now retired

Simon Willison · Simon Willison

What it covers: GitHub Models, a tool for accessing large language models (LLMs) and a model playground, has been retired.

Why it matters now: Users of GitHub Models, particularly those with workflows in GitHub Actions, need to update their systems.

Key takeaway: GitHub Models provided a unified API and allowed GitHub Actions to use existing API keys for LLM prompts.

Benefits and impact: The service simplified building Continuous AI applications within GitHub's ecosystem.

Read the full breakdown

GitHub Models is no longer available. The service offered a unified API for various LLM providers and a model playground. A key feature was allowing GitHub Actions to use the environment's GitHub API key for LLM calls. This facilitated the creation of Continuous AI applications. The author speculates that the shutdown may be due to the high cost of providing free or subsidized tokens for coding agent patterns. The author updated their workflow to use an OpenAI API key with GPT-5.6 Luna.

alchemy-utils 0.1a0

Simon Willison · Simon Willison

What it covers: Simon Willison released alchemy-utils 0.1a0, a new Python library and CLI utility. It aims to be a database-agnostic version of his sqlite-utils library.

Why it matters now: This project explores using AI models like Codex and GPT-5.6 Sol Ultra for rapid prototype development. It demonstrates AI's capability in generating functional code from high-level requirements.

Key takeaway: alchemy-utils provides core database operations like insert, upsert, create, and update across multiple database engines. It uses SQLAlchemy as its backend.

Benefits and impact: The library supports PostgreSQL, SQLite, and DuckDB, offering broader compatibility than sqlite-utils. It allows developers to use a consistent API for various databases.

Read the full breakdown

Simon Willison developed alchemy-utils 0.1a0, a new Python library and command-line utility. He used AI models, Codex and GPT-5.6 Sol Ultra, to build the prototype. The goal was to create a database-agnostic tool similar to his existing sqlite-utils library. It supports core database functions such as inserting, upserting, creating, and updating data. The library is built on SQLAlchemy, allowing it to work with multiple database engines. Initial tests confirm compatibility with PostgreSQL, SQLite, and DuckDB.
