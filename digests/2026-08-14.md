### GitHub Models is now retired
*Simon Willison · Simon Willison* · [https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/](https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/)

- **What it covers:** GitHub Models, a tool for accessing large language models (LLMs) and a model playground, has been retired.
- **Why it matters now:** Users of GitHub Models, particularly those with workflows in GitHub Actions, need to update their systems.
- **Key takeaway:** GitHub Models provided a unified API and allowed GitHub Actions to use existing API keys for LLM prompts.
- **Benefits and impact:** The service simplified building Continuous AI applications within GitHub's ecosystem.

### alchemy-utils 0.1a0
*Simon Willison · Simon Willison* · [https://simonwillison.net/2026/Aug/12/alchemy-utils/](https://simonwillison.net/2026/Aug/12/alchemy-utils/)

- **What it covers:** Simon Willison released alchemy-utils 0.1a0, a new Python library and CLI utility. It aims to be a database-agnostic version of his sqlite-utils library.
- **Why it matters now:** This project explores using AI models like Codex and GPT-5.6 Sol Ultra for rapid prototype development. It demonstrates AI's capability in generating functional code from high-level requirements.
- **Key takeaway:** alchemy-utils provides core database operations like insert, upsert, create, and update across multiple database engines. It uses SQLAlchemy as its backend.
- **Benefits and impact:** The library supports PostgreSQL, SQLite, and DuckDB, offering broader compatibility than sqlite-utils. It allows developers to use a consistent API for various databases.

*Scharon Harding · Ars Technica* · [https://arstechnica.com/gadgets/2026/08/pet-owners-say-smart-pet-feeder-outage-led-to-furry-ones-going-unfed/](https://arstechnica.com/gadgets/2026/08/pet-owners-say-smart-pet-feeder-outage-led-to-furry-ones-going-unfed/)

- **What it covers:** A smart pet feeder experienced an outage. This left pets unfed. Pet owners reported the issue.
- **Why it matters now:** The incident highlights reliability concerns with smart home devices. Users depend on these devices for essential tasks. Outages can have immediate negative consequences.
- **Key takeaway:** Dependence on smart devices for critical functions carries risks. Device failures can directly impact user well-being. Trust in these technologies can be easily broken.
- **Benefits and impact:** This event serves as a cautionary tale for IoT device manufacturers. It emphasizes the need for robust backup systems. It also stresses clear communication during service disruptions.
