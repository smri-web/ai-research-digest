### Tree Appreciator
*Simon Willison · Simon Willison* · [https://simonwillison.net/2026/Oct/14/tree-appreciator/](https://simonwillison.net/2026/Oct/14/tree-appreciator/)

- **What it covers:** A developer used Claude Opus 5.5 Max to create a game called 'Tree Appreciator'. The game is a spot-the-difference type featuring two algorithmically generated trees.
- **Why it matters now:** This project demonstrates the capability of large language models like Claude to generate complex, interactive applications from simple prompts.
- **Key takeaway:** Prompting AI with 'make sure it is fun' can lead to surprisingly compelling and well-designed game mechanics.
- **Benefits and impact:** AI can significantly reduce development time for creative projects, as Claude spent 3 hours and 7 minutes generating the game.

### llm-gemini 0.35
*Simon Willison · Simon Willison* · [https://simonwillison.net/2026/Oct/13/llm-gemini/](https://simonwillison.net/2026/Oct/13/llm-gemini/)

- **What it covers:** llm-gemini 0.35 adds support for the new Gemini 4 Argon model. This model is now available through the Gemini API and a $100/month subscription.
- **Why it matters now:** The Argon model is currently priced at $2/million input tokens and $10/million output tokens, matching GPT-6 Sol. This price is set to double on December 1st.
- **Key takeaway:** Argon performs well in benchmarks, costing $2,407 to run a specific benchmark. This places it competitively against other models.
- **Benefits and impact:** The new model offers a cost-effective option for AI tasks, at least until its price increases. Its performance suggests it is a strong contender in the current market.
